# 🤖 Simple Chatbot

A basic chatbot project built to simulate simple human-like conversation using predefined logic.

---

## 📌 Project Overview

Simple Chatbot is a beginner-friendly project that demonstrates how conversational logic works in a chat interface.  
The bot responds to user inputs based on simple conditions and predefined responses.

This project was built for learning purposes and to understand basic interaction handling.

---

## 🚀 Features

- Interactive chat interface
- Instant bot responses
- Simple conditional logic
- Lightweight and easy to understand

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

---

## 📂 How to Run the Project

### Option 1: Run Locally

1. Clone the repository:

git clone https://github.com/kkroffl/Simple-Chatbot.git

2. Navigate to the project folder:

cd Simple-Chatbot

3. Open the `index.html` file in your browser.

---

### Option 2: Direct Download

- Click **Code → Download ZIP**
- Extract the folder
- Open `index.html` in your browser

---

## 💬 How It Works

- User types a message.
- JavaScript processes the input.
- The bot checks predefined conditions.
- A response is displayed instantly.
